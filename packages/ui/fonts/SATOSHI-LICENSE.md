# Satoshi

Satoshi is a typeface by the Indian Type Foundry, distributed through [Fontshare](https://www.fontshare.com). It is free for personal and commercial use under the Fontshare EULA, which does not permit redistribution of the font as a font product.

This is a private repository. `Satoshi-Variable.ttf` ships here only so nurb's own apps can serve it, never as a font offered for download or resale.
