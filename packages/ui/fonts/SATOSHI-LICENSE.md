# Satoshi

Satoshi is a typeface by the Indian Type Foundry, free under the ITF Free Font License from [Fontshare](https://www.fontshare.com). That license lets nurb embed it in its own app and serve it on its own pages, and it forbids putting the font file in a public repository or handing it to anyone else.

So this repository does not contain it. `scripts/fetch-satoshi.sh` downloads your own copy from Fontshare into this folder, and the workbench and desktop builds run it first. Without the file, headlines fall back to Instrument Sans.
